# 玄枢 XuanShu v0.2.6 · 发布说明

> 性能专项：让玄枢「想用的时候最快连上」。

## 这个版本解决什么

你反馈玄枢跟其他 agent 联调时「进场不稳」，第一次发起请求有时 30 秒以上才返回。根因确认：**玄枢此前没有连接级超时**——一旦第一个候选上游不可达或极慢，会在底层 TCP 重传上耗 20–30 秒才切换到下一个，体感就是「卡 30 秒」。本版从「超时兜底」和「预热保活」两头下手。

## 变更

### 修复：第一次请求不再卡 30 秒
- **连接建立超时（默认 10s）**：DNS+TCP+TLS 整体硬超时，不可达候选立即切换下一候选。
- **非流式响应超时（默认 20s）**：连上了但上游不回包，也会在 20s 内切换，不再干等到底层 600s 超时。

### 新增：想用时连接已是热的
- **启动预热 + 空闲保活**：玄枢启动即对所有启用频道预解析 DNS、建立热连接并探测可达性；**连不上的频道自动暂时剔除**，你发起请求时不会再撞它；之后每 5 分钟持续保活，很久没用也不会变冷。
- **设置页新增「连接与预热」分组**：可调整连接超时、响应超时、预热开关与间隔。

## 升级注意
- 配置向后兼容，覆盖安装即可；新设置项走默认值，无需手动配置。
- 默认已开启预热，启动后约几秒内完成首次探测。
